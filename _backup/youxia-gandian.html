BD 核心思路（4个关键修正）

  1. 选梦花而非狱火：感电的卡点不是小怪，而是BOSS阶段输出不够，梦花对BOSS的输出高于狱火。
  2. 复仇+破甲+落井下石体系，而非灌注。掌控2用暗影步-猛攻，不是绳网或隐蔽等。生存不够可以挂机凹词条回BOSS，难的是提高输出上限。
  3. 四件套而非二件套：噬魂魔4件套"霹雳龙"还能触发灵光一现/刺耳怒吼/12电/易伤手套！
  4. 附伤概率 > 暴击率 > 幸运：附伤概率必须达到85%以上，不够必须用霸遗来补充。幸运的重要性下降，靠项链/护腕补充就足够了，不用词条专门洗幸运。

陷阱 · 漩涡
在敌人脚下布置陷阱，造成200%攻击的物理伤害并施加70%移速降低，持续4秒。符文效果：元素伤害提升5%；陷阱不再爆炸，向周围喷射寒冰漩涡，2.5秒内造成总计250%攻击的冰元素伤害并施加寒冷；最终减伤提升5%；陷阱造成伤害时施加冻伤（持续5秒，每次受击额外获得1层，叠加6层后额外受到3次攻击100%的冰元素伤害，并有20%概率冻结1秒，清除冻伤层数，不可暴击）。

暗影步 · 猛攻

输出循环与操作要点
  1. 起手：陷阱-漩涡铺地 → 暗影步-猛攻突进（触发破甲）→ 开启复仇-暴雨 → 重型武器-感电持续输出。
  2. 核心机制：暗影步-猛攻的50%概率破甲 + 复仇-暴雨的5%概率破甲 + 落井下石被动（破甲状态伤害+20%，对首领双倍）= 复仇破甲体系。
  3. 感电触发：重型武器-感电符文的电流子弹必定产生电弧，电弧可以触发附加伤害，并受到伏特火花被动的加成（每10秒翻倍，最多9次）。
  4. 生存注意：降急速机制被修复后，没法通过降急速让怪物冻住了，秘境刚入场时暴毙率极高。后面叠好暗影斗篷盾才安全。这套猛攻可以换固守，提高生存率。
  5. BOSS阶段：感电的卡点是BOSS输出不够，所以选梦花（对BOSS输出高于狱火）。梦花的梦境精华对抗首领时每层额外获得16%伤害强化，最多6层=96%额外伤害强化。
